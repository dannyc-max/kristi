# The Art is Coming from Inside the House: website

Static site, no build step. Open `index.html` in a browser.

- `index.html`: the whole site (art, process, shop, journal, fairs, newsletter sign-up)
- `assets/logo/`: logo in SVG, transparent PNG and cream PNG
- `print/signup-sheet.html`: clipboard sign-up sheet for the booth (print from a browser)
- `../docs/marketing-plan.md`: newsletter cadence, giveaway, content plan
